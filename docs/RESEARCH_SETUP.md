# Интернет-поиск и Deep Research

## Архитектура

Интерфейс вызывает отдельную Supabase Edge Function `research`. Она проверяет Supabase Auth, прежний список разрешённых пользователей GenAPI и MFA. Поиск выполняет Tavily Search, чтение страниц — Tavily Extract. Само приложение не загружает произвольные URL и не исполняет код сайтов. Генерация остаётся в существующем шлюзе `genapi`.

Один пользовательский запрос создаёт одну задачу. В режимах «Несколько ИИ» и «Мульти-ИИ» все выбранные модели используют один набор сохранённых материалов. Глубокое исследование составляет до четырёх запросов, читает до десяти страниц, сопоставляет материалы и формирует отчёт. Это собственный ограниченный процесс, а не платный endpoint Tavily Research.

Задачи, события, источники и квитанции платных вызовов сохраняются в Postgres. Короткие шаги исполняются через `EdgeRuntime.waitUntil`; Cron раз в минуту продолжает очередь, если вкладка закрыта. После повторного открытия чата можно продолжить получение ответа. Незавершённый платный вызов имеет состояние `unknown` и автоматически не повторяется.

## Серверные настройки

1. В Supabase → Edge Functions → Secrets должен существовать `TAVILY_API_KEY`. Ключ вводит владелец. Его нельзя добавлять в файлы сайта, SQL, Git или сообщения.
2. Используются существующие `GENAPI_API_KEY`, `GENAPI_ALLOWED_ORIGINS` и `GENAPI_ALLOWED_USER_IDS`. Встроенные серверные переменные Supabase функция получает из окружения.
3. Миграция `202611100002_research.sql` создаёт четыре таблицы, RLS, серверные RPC и поля `research_job_id`/`citations` в двух существующих таблицах сообщений. Авторизация, Storage и вложения не заменяются.
4. Миграция `202611100003_research_worker.sql` включает pg_cron/pg_net, создаёт приватный токен в Vault и расписание `ai-studio-research-worker`. Токен не нужно копировать или выводить. Для другого проекта необходимо изменить адрес функции в SQL **до** применения миграции.
5. Обе миграции уже применены к текущему проекту через Dashboard. Повторно выполнять их нельзя. История миграций Supabase CLI требует отдельного согласованного выравнивания перед будущим `db push`.
6. Сборка: `npm ci`, `npm run build:edge`, `npm run build:research`. В Dashboard публикуются содержимое `build/genapi/index.ts` и `build/research/index.ts` в соответствующие функции. Файлы сборки исключены из Git.
7. У обеих функций `Verify JWT with legacy secret` выключен. Это согласовано с владельцем; пользовательскую сессию независимо проверяет общий модуль Auth через `/auth/v1/user`. Вызов `tick` принимает только приватный серверный токен и не создаёт задач.

## Стоимость и ограничения

Проверено по [официальной документации Tavily](https://docs.tavily.com/documentation/api-credits) 10.11.2026: бесплатный план — 1000 кредитов/месяц; basic Search — 1 кредит; advanced — 2; basic Extract — 1 кредит за 5 успешно прочитанных страниц. Pay-as-you-go — $0.008/кредит. Платный тариф автоматически не подключается приложением.

В этой реализации обычный поиск резервирует 2 кредита (1 поиск + 1 пакет чтения). Deep Research резервирует 12 кредитов; текущий алгоритм использует до 4 advanced-поисков и 2 пакетов чтения, то есть до 10 кредитов. Резерв намеренно консервативен и не возвращается после удаления чата. Общий предел приложения — 800 зарезервированных кредитов в календарный месяц UTC: максимум 400 обычных задач либо 66 глубоких, если использовать только один тип. В PAYG эквивалент 2 кредитов — $0.016, 12 — $0.096; расходы GenAPI оплачиваются отдельно.

На пользователя: 20 задач за скользящие 24 часа, из них до 3 глубоких; одна активная задача одновременно; до 5 ответов моделей на задачу. Ответ с источниками требует отдельного вызова выбранной модели и проверки утверждений через Gemini. Deep Research дополнительно использует DeepSeek для плана и сопоставления. Usage сохраняется в серверном журнале; это ещё не пользовательская система баланса или тарифов.

## Цитирование и безопасность

В контекст попадают только реально прочитанные страницы. Поисковые сниппеты не считаются подтверждением. Контекст ограничен 40 тыс. символов, страница — 20 тыс., ответ Tavily — 2 MiB, пакет чтения — 5 URL. HTTPS-адреса проверяются; IP, локальные адреса, credentials и нестандартные порты отклоняются. Сетевой адрес вызова фиксирован на API Tavily; фактическую загрузку страниц выполняет провайдер.

Модель возвращает утверждения с ID источника и точной цитатой. Сервер проверяет наличие цитаты в тексте и отдельно проверяет смысловую поддержку через Gemini. Неподтверждённые утверждения исключаются. Ссылки берутся из БД, а не из текста модели. В интерфейсе используются текстовые узлы; HTML страниц не исполняется. Материалы сайтов обозначены как недоверенные данные.

RLS разрешает чтение только владельцу; создание/изменение исследовательских таблиц и списание бюджета доступны только серверу. Триггер сообщений проверяет владельца, чат и принадлежность цитат задаче. Удаление чата удаляет его материалы, но сохраняет серверный журнал расходов и квитанции ответов. Полного обезличивания аккаунтов и сроков автоматического удаления пока нет.

Проверка цитаты и отдельная модель снижают риск ошибок, но не доказывают истинность публикации. Сайты могут быть устаревшими, противоречивыми или недоступными. Дата получения отображается; она не равнозначна дате обновления страницы. Актуальные запросы запрашивают у Tavily кэш не старше 24 часов; это не гарантия полноты или мгновенной свежести.

## Проверки и эксплуатация

`npm test` проверяет существующие чаты/вложения и новые сценарии: общий поиск, идемпотентность, таймауты, неполное чтение, цитаты, права, все три режима и безопасное отображение. `supabase/tests/research-rls.sql` выполняет проверки в откатываемой подтранзакции. Итог реальных испытаний фиксируется отдельно в отчёте этапа.

На время сквозных испытаний переключатель скрыт. Для него используется `?research_preview=1`. Это только флаг интерфейса, а не средство контроля доступа: сервер всегда требует авторизацию и разрешённый UID. До успешного реального теста всех режимов флаг нельзя включать по умолчанию.

Для аварийного отключения новых поисков убрать `TAVILY_API_KEY` либо вернуть скрытый переключатель; для остановки фоновой очереди отключить `ai-studio-research-worker` в Supabase Cron. Уже начатый запрос может быть оплачен. Откат приложения — предыдущий проверенный коммит; миграции с пользовательскими данными не удалять.
