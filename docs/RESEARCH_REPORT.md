# AI Studio 3.0 — интернет-поиск и Deep Research

Дата проверки: 10 ноября 2026 года.

Статус: этап реализован и опубликован в пределах перечисленных ниже ограничений. Проверен реальный путь от запроса через Tavily Search и Extract до содержательного ответа GenAPI, цитат и сохранённой истории. HTTP 200 сам по себе не считался успешным результатом.

## Публикация и использование

Код выпуска: `f2cbf2e`. [GitHub Pages успешно опубликовал именно этот коммит](https://github.com/d-ekimov/AI_Studio3.0/actions/runs/42882317622). На [обычном адресе AI Studio](https://d-ekimov.github.io/AI_Studio3.0/) проверено отображение переключателя «Интернет» без параметра предпросмотра. По умолчанию поиск выключен. Владелец уже сохранил ключ Tavily в Supabase; дополнительных ручных действий для включения этого выпуска не требуется.

В любом из трёх режимов выбери «Поиск» или «Глубокое исследование» и отправь запрос до 500 символов. Под ответом можно раскрыть «Источники и подтверждающие фрагменты». Ссылки рядом с утверждениями открывают оригиналы страниц. Стоимость ответов GenAPI оплачивается отдельно от кредитов Tavily.

Service Worker обновлён до `ai-studio-shell-v8`. Файлы `app.js` и `research-client.js` подключены с версией `research-v1`, чтобы после обновления не смешивались старый интерфейс и новая логика восстановления. Сохранён прежний сетевой приоритет HTML/JS/CSS и очистка только кешей оболочки AI Studio. Внешние запросы Supabase/GenAPI не кешируются этим обработчиком.

Настройка legacy JWT для `research` выключена с отдельного разрешения владельца. Анонимные пользовательские запросы функция отклоняет сама; приватный планировщик может только продолжить ранее авторизованную задачу. Существующая авторизация GenAPI, список разрешённых пользователей и MFA сохранены.

Повторно выполнены **9 живых SQL-проверок** из `supabase/tests/research-rls.sql`: права владельца и чужого `sub`, запрет клиентских записей и расходных RPC, отсутствие клиентского чтения журнала, проверка привязки к чату, идемпотентность и сохранение резерва при удалении тестового чата. Все синтетические данные откатились в подтранзакции. Два независимых входа в браузере для этой проверки не использовались.

Storage и система вложений не заменялись. Миграции не следует запускать повторно. Перед будущим использованием Supabase CLI нужно отдельно согласовать выравнивание истории миграций, применённых вручную.

## Расходы и ограничения

Обычная задача резервирует 2 кредита Tavily, глубокая — 12. Текущий глубокий процесс использует до 10: четыре advanced-поиска по 2 и два basic Extract по 1. Общий предел приложения — 800 зарезервированных кредитов за месяц UTC; на пользователя — 20 задач за скользящие 24 часа, из них до 3 глубоких; одновременно одна активная задача. До пяти ответов моделей на одну задачу. Удаление чата не возвращает резерв, поэтому расходный лимит нельзя обойти удалением истории.

В ходе испытаний создано 12 задач и зарезервировано 34 кредита. В успешных квитанциях Tavily подтверждено 22 кредита. Это не окончательный счёт провайдера: для некоторых первоначальных сбоев сохранён консервативный статус `unknown`. Фактические начисления нужно сверять с кабинетом Tavily. Вызовы GenAPI и Supabase оплачиваются/учитываются отдельно; расход того же ключа вне AI Studio не входит в локальный журнал приложения.

По [тарифам Tavily](https://docs.tavily.com/documentation/api-credits), проверенным 10.11.2026, бесплатно предоставляется 1000 кредитов в месяц; PAYG — $0.008/кредит. Эквивалент верхнего резерва обычной задачи — $0.016, глубокой — $0.096 без GenAPI. Само приложение не подключает платный тариф. Для Deep Research используются DeepSeek для плана/сопоставления и Gemini для смысловой проверки; выбранная пользователем модель формирует итоговый ответ.

Остальные ограничения:

- До пяти страниц для обычного поиска и десяти для глубокого; до 40 тыс. символов исходного контекста суммарно. Страницы и предварительное сопоставление могут усекаться. Глубокий итог ограничен 12 основными утверждениями, генерации — установленными серверными лимитами токенов.
- Недоступные, закрытые или требующие исполнения JavaScript страницы могут не читаться. Поисковые сниппеты не подменяют прочитанный документ. Несколько URL одного издателя не являются независимыми подтверждениями.
- Дата получения не означает дату публикации/обновления. Нельзя гарантировать полноту выдачи, отсутствие ошибок источника или мгновенную свежесть данных.
- Автоматических повторов платных вызовов нет. Новый ответ — отдельная осознанная генерация. Если сами источники не получены, нужно отправить новый поисковый запрос.
- При включённом поиске подтверждаемые утверждения итогового ответа проверяются по веб-источникам. Полноценное цитирование частных вложений вместе с веб-страницами в этой версии не реализовано; для отдельного анализа файлов следует выключить поиск. Обычный мультимодальный чат сохраняет прежнюю работу.
- Журнал расходов и квитанции остаются серверными после удаления чата. Автоматические сроки хранения, полное обезличивание аккаунта и пользовательская биллинговая панель в этот этап не входят.
- Смысловая проверка также выполняется моделью и может ошибаться. Техническая проверка точных цитат не заменяет редакционную оценку выводов и надёжности издателя.

## Исправленные проблемы

Реальные испытания выявили пустую выдачу из-за жёсткого фильтра возраста кеша Tavily, неструктурированный ответ и исчерпание токенов служебным проверяющим DeepSeek без финального результата. Фильтр убран, JSON-режим задан явно, смысловая проверка переведена на Gemini с контекстом источника. Добавлены безопасная структурная диагностика без текстов/ключей, явное ручное восстановление без повторного поиска и версии ресурсов интерфейса. Отмена задачи защищена от перезаписи результатом пустого Extract.

Работа по этапу остановлена после выпуска и проверки. Следующие изменения требуют нового задания.
